# Package manifest

- `CHDT/`: CHDT model, training entry point, trajectory exporter, and ALPACA configuration.
- `data/`: minimal longitudinal dataset infrastructure and ALPACA adapter.
- `data/alpaca/*.csv`: fixed synthetic development, placebo, and statin cohorts.
- `requirements.txt`: tested Python dependencies.
- `README.md`: installation, execution, and output instructions.
- `DATA_README.md`: cohort descriptions.
- `ANONYMIZATION_CHECKLIST.md`: package anonymization scope.
